Política de Privacidade

Sementes Pipeline app · atualizada em 22/11/2026

O Sementes Pipeline app é uma ferramenta de uso próprio do canal Sementes da Inspiração Bíblica. Ele não é oferecido ao público.

Dados acessados

Com a autorização do dono da conta, o app usa a YouTube Data API apenas para enviar vídeos, atualizar títulos, descrições, miniaturas e playlists, e ler informações básicas do próprio canal.

Uso e armazenamento

Os dados são usados só para publicar e organizar os vídeos do canal. Os tokens de acesso ficam guardados de forma privada e não são vendidos, compartilhados nem usados para publicidade. Nenhum dado de espectadores, incluindo crianças, é coletado pelo app.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Ao usar o app você também concorda com os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
